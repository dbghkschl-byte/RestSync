# RestSync — SYNCLAB

목표 도착 시각과 내비게이션 예상 주행 시간을 바탕으로 휴식 시간을 계획하고, 출발할 시간을 알려주는 Pleos Connect 앱입니다.

## 실행 방법

1. 아래 APK 파일을 내려받아 Pleos Connect 에뮬레이터에 설치합니다.
2. 앱 목록에서 RestSync를 실행합니다.
3. 목적지를 검색·선택하면 Pleos 기본 내비게이션으로 전환됩니다.
4. RestSync를 다시 열어 목적지를 변경하거나 **휴식 · 휴게소 찾아줘**를 선택합니다.
5. 추천 휴게소를 경유지로 등록합니다.
6. 휴게소 도착과 정차·P단을 확인하고 휴식 시간을 선택합니다.
7. 출발 알림을 확인한 뒤 휴식을 마치고 기본 내비 안내를 이어갑니다.

## 테스트 환경 및 필요한 설정

- 개발 도구: Android Studio
- 개발 언어: Kotlin
- Android 환경: Android 14 / API 34 Automotive, x86_64
- 인터넷 연결과 Pleos 기본 내비게이션 서비스가 필요합니다.
- 외부 API를 사용하는 검색 기능은 앱 설정에 유효한 Kakao REST API 키를 입력하고 해당 서비스 사용 설정을 활성화해야 합니다.
- 알림·위치·마이크 등 필요한 권한은 앱의 요청에 따라 허용합니다.

- 화면 해상도: 2560 × 1440
- 화면 밀도: 160 dpi
