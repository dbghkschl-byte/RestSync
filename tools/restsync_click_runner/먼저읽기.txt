포인터 업데이트
RestSync 버튼을 누르기 전에 보라색 마우스 모양 포인터가 이동하고 클릭 위치에 원이 표시됩니다.
앱 화면과 앱 팝업 위에 그리는 개발 빌드용 시각 효과이며, 실제 클릭은 기존 버튼 입력을 그대로 사용합니다.
Pleos 내비 화면에는 RestSync 포인터를 덮어 그리지 않습니다. 별도 오버레이 권한은 필요하지 않습니다.
포인터 표시 중 화면 또는 시연 단계가 바뀌면 해당 클릭을 취소합니다.
포인터 추가 후 일반 화면·설정 팝업 표시와 실제 설정 열기/닫기 클릭을 에뮬레이터에서 확인했습니다.
포인터가 포함된 전체 자동 시연 통과 결과와 별도 팝업 확인 결과는 validation 파일에 있습니다.

이 PC에서는 실행기를 켠 상태에서 실제 앱 설정 버튼을 통한 전체 자동 클릭이 통과했습니다.
실행기가 PC에서 켜져 있는 동안 설정 버튼으로 다시 실행할 수 있습니다.
PC 재부팅 또는 실행기 프로세스 종료 후에는 launch_runner.cmd를 다시 한 번 켜야 합니다.
앱만으로 외부 내비 화면의 버튼을 주입하는 방식이 아니라, 개발 PC의 ADB UI 자동화와 연결된 기능입니다.

전체 시연 영상을 촬영하는 방법
에뮬레이터 콘솔 녹화로 최대 15분의 무음 WebM을 저장하고 시연 종료 후 녹화를 마칩니다.
이 녹화를 지원하지 않는 에뮬레이터는 기존 ADB screenrecord로 대체하며, 대체 MP4는 무음·최대 180초라 일부 구간만 담길 수 있습니다.
결과 JSON의 videoFullWalkthrough 및 videoBackend로 녹화 범위를 확인할 수 있습니다.
음성도 남기려면 별도 PC 화면 녹화에서 시스템/앱 오디오를 함께 녹음하세요.

재생 제어
실제 앱의 안내 바에서 일시정지·재개·재시작·다음 장면·시연 종료를 사용할 수 있습니다.
일시정지는 자동 클릭만 멈춥니다. 실제 휴식 타이머와 이미 전송한 내비 요청은 계속됩니다.
재시작은 등록한 선택 경유지를 기존 확인·정리 흐름으로 처리한 뒤 새 목적지 검색부터 진행합니다.
종료는 자동 클릭을 멈추며, 이미 수행한 실제 목적지/경유지 변경을 이전 경로로 복원하지 않습니다.

실제 연동과 녹화용 값의 구분
목적지 검색은 실제 Photon/OpenStreetMap 검색이며, 휴게소 비교에는 앱에 저장된 카카오 길찾기 키를 사용합니다.
실제 Pleos SDK로 목적지·경유지를 요청하고 등록 상태와 최종 목적지를 다시 확인합니다.
좌표를 0,0으로 반환하는 기기에서는 기존 구현대로 등록 이름과 최종 목적지를 확인하며 좌표 검증으로 표시하지 않습니다.
휴식 시작 후 첫 실제 Pleos ETA로 녹화용 도착 목표를 설정합니다: 휴식 시작 + 실제 주행 ETA + 55분.
이 중 안전/사전 알림 여유 20분과 휴식 여유 35분을 사용해 30분 → 연장 35분 → 가상 정체 반영 약15분이 됩니다.
교통 정체 +20분은 실제 교통 관측값이 아닌 명시적인 녹화용 시연값입니다.
시간 가속은 휴식 시작·도착 목표를 같은 양만큼 옮겨 마지막 8초를 보여줍니다. 실제로 30분을 쉰 것이 아닙니다.
원래 저장했던 도착 목표는 녹화 시나리오에 맞게 바뀌며, 실제 목적지와 경유지 등록도 수행합니다.

실행기는 Emulator/QEMU 확인을 통과한 기기만 허용하며 실제 차량/일반 실기기는 실행 대상에서 제외합니다.
정차/P단 확인 버튼도 개발용 에뮬레이터에서 자동 클릭합니다. 실제 차량의 정차를 감지하거나 보증하지 않습니다.

자동 클릭 버튼은 개발 빌드에서만 표시됩니다. 실제 차량용 release 기능을 뜻하지 않습니다.

실행기 연결
Python과 Android SDK platform-tools/adb.exe를 사용합니다. 현재 PC의 Python 경로는 python_path.txt에 있습니다.
PC가 달라져 해당 경로가 없으면 launch_runner.ps1의 설치된 Codex 런타임/Python 검색을 사용합니다.
PC 수신 주소는 127.0.0.1:8765로 제한합니다. 앱은 에뮬레이터의 호스트 루프백 주소로 연결합니다.
HTTP는 고정 동작만 받으며 Origin·Host·전용 헤더·빈 JSON 본문을 검사합니다. 임의 셸 명령을 HTTP로 받지 않습니다.
저장된 사용자 키와 앱 데이터는 배포 ZIP에 포함하지 않았습니다.
